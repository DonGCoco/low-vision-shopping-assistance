# Third-party components

This archive contains project integration code alongside third-party model/framework code. Do not assume all source files were authored by the thesis author.

- DeblurGAN: Kupyn et al., *DeblurGAN: Blind Motion Deblurring Using Conditional Adversarial Networks*, https://arxiv.org/abs/1711.07064 . The recovered README describes an existing PyTorch implementation and acknowledges https://github.com/victoresque/pytorch-template . Its exact upstream repository and applicable license need to be confirmed before redistribution under a new license.
- Qwen2-VL: https://github.com/QwenLM/Qwen2-VL . Model and software licenses apply separately.
- Whisper: https://github.com/openai/whisper . Used for speech recognition, not speech synthesis.
- GPT-SoVITS: https://github.com/RVC-Boss/GPT-SoVITS . Described in the thesis; its service implementation is not present in the recovered archive.
- ImageNet/ILSVRC: data are not redistributed here. Follow the dataset provider's terms.

Original recovered README files are retained. No checkpoints, bundled Python environments or executables are distributed in this repository.
